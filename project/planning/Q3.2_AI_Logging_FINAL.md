## Overview

**What:** AI-powered natural language logging system that allows users to log meals, workouts, and weight by typing (or speaking, in future) natural descriptions. AI parses the input, asks follow-up questions if needed, calculates calories/macros, and logs the entry with user confirmation.

**Why:** Logging is the #1 friction point in fitness apps. Traditional food database search is slow and tedious. AI logging reduces friction by 80%, making daily tracking effortless. Users can type "grilled chicken with rice and broccoli" instead of searching for each item separately.

**When:** Accessed from Log tab (primary) or quick-log buttons throughout the app. Used daily by all active users (average 3-5 logs per day).

**Dependencies:**
- Q3.0 Navigation & App Shell (Log tab structure)
- OpenAI API (GPT-4o-mini for parsing)
- Q0 Data Structures (LoggedMeal, LoggedWorkout, WeightEntry interfaces)
- User profile (dietary restrictions, eating pattern)

## User Stories

### Primary User Story: AI Meal Logging
**As a** user who just ate a meal
**I want** to log it by typing what I ate
**So that** I can track my nutrition without tedious database searching
**Acceptance Criteria:**
- [ ] Can type natural description ("chicken burrito bowl with guac")
- [ ] AI understands complex meals with multiple ingredients
- [ ] AI asks follow-up questions for ambiguous items (portion size, preparation)
- [ ] Confirmation screen shows calculated calories and macros
- [ ] Can edit AI's calculations before confirming
- [ ] Meal logs to today's date with current timestamp

### AI Workout Logging Story
**As a** user who completed a workout
**I want** to log it by typing what I did
**So that** I can track my exercise without manual entry
**Acceptance Criteria:**
- [ ] Can type natural description ("30 min run" or "chest and triceps workout")
- [ ] AI estimates calories burned based on user profile
- [ ] AI asks for missing details (distance, intensity, weight used)
- [ ] Confirmation screen shows workout details and calories
- [ ] Can edit before confirming
- [ ] Workout logs to today's date with current timestamp

### Weight Logging Story
**As a** user who weighed myself
**I want** to log my weight quickly
**So that** I can track progress over time
**Acceptance Criteria:**
- [ ] Can type natural description ("182.5" or "182.5 lbs")
- [ ] AI understands lbs and kg units
- [ ] Converts to user's preferred unit from settings
- [ ] Shows trend (up/down from last weigh-in)
- [ ] Weight logs to today's date with current timestamp

### Restaurant Recognition Story
**As a** user who ate at a chain restaurant
**I want** the AI to recognize the restaurant and menu items
**So that** I get accurate calories without guessing
**Acceptance Criteria:**
- [ ] AI recognizes major chains (Chipotle, Subway, Starbucks, McDonald's, etc.)
- [ ] AI knows standard menu items and their calories
- [ ] AI asks which size/customizations
- [ ] Accurate calorie data (within 5% of official nutrition)

### Manual Entry Fallback Story
**As a** user when AI fails to parse my input
**I want** a manual entry form as backup
**So that** I can still log my meal/workout
**Acceptance Criteria:**
- [ ] If AI fails after 2 attempts → Offer manual entry
- [ ] Manual form has all fields (calories, macros, name, etc.)
- [ ] Manual entry saves with same data structure

## User Flow

### Meal Logging Flow

```
Log Tab
    ↓
[Tap "Log Meal" button]
    ↓
AI Text Input Screen
    ↓
User types: "grilled chicken breast with brown rice and steamed broccoli"
    ↓
[Tap "Log It" or press Enter]
    ↓
Loading (AI parsing, 1-3 seconds)
    ↓
    ├─→ [Clear input, no ambiguity] → Confirmation Screen
    │       ├─→ Shows: Grilled Chicken Breast (6 oz, 280 cal)
    │       │          Brown Rice (1 cup, 215 cal)
    │       │          Steamed Broccoli (1 cup, 55 cal)
    │       │          TOTAL: 550 cal, 50g protein, 60g carbs, 10g fat
    │       ├─→ [Edit] → Manual adjustment
    │       └─→ [Confirm] → Logged! → Success toast → Back to Log tab
    │
    ├─→ [Ambiguous] → Follow-up Question
    │       Example: "How was the chicken prepared?"
    │       Options: [Grilled] [Fried] [Baked] [Other]
    │       User selects → Loading → Confirmation Screen
    │
    ├─→ [Missing portion] → Follow-up Question
    │       Example: "How much chicken? (in ounces)"
    │       Input: Number picker (1-16 oz)
    │       User enters → Loading → Confirmation Screen
    │
    ├─→ [Restaurant detected] → Follow-up Question
    │       Example: "Was this from Chipotle?"
    │       [Yes] [No, just homemade]
    │       If Yes → "Which bowl?" → Menu selection → Confirmation
    │       If No → Continue with regular parsing
    │
    ├─→ [AI uncertain] → Follow-up Question
    │       Example: "Is this correct?"
    │       Shows best guess with [Yes] [No, let me clarify]
    │       If No → Text input again (2nd attempt)
    │
    └─→ [AI failed after 2 attempts] → Manual Entry Fallback
            "I'm having trouble understanding. Would you like to enter manually?"
            [Enter Manually] [Try Again] [Cancel]
```

```typescript
function calculateWorkoutCalories(
  type: 'cardio' | 'strength',
  duration_min: number,
  intensity: 'light' | 'moderate' | 'vigorous',
  user_weight_lbs: number
): number {
  // MET values (Metabolic Equivalent of Task)
  const MET = {
    cardio: {
      light: 4.0,     // Walking
      moderate: 7.0,  // Running 5-6 mph
      vigorous: 10.0  // Running 7+ mph
    },
    strength: {
      light: 3.0,     // Light weights
      moderate: 5.0,  // Moderate weights
      vigorous: 6.0   // Heavy weights
    }
  };

  const met = MET[type][intensity];
  const weight_kg = user_weight_lbs * 0.453592;

  // Calories = MET × weight (kg) × duration (hours)
  const calories = met * weight_kg * (duration_min / 60);

  return Math.round(calories);
}
```

### Restaurant Detection Logic

```typescript
const RESTAURANT_KEYWORDS = {
  chipotle: ['burrito', 'bowl', 'chipotle', 'guac', 'queso'],
  subway: ['subway', 'footlong', 'sub'],
  starbucks: ['starbucks', 'frappuccino', 'latte', 'venti', 'grande'],
  mcdonalds: ['big mac', 'quarter pounder', 'mcdonalds', 'happy meal'],
  // ... more restaurants
};

function detectRestaurant(input: string): string | null {
  const lowerInput = input.toLowerCase();

  for (const [restaurant, keywords] of Object.entries(RESTAURANT_KEYWORDS)) {
    for (const keyword of keywords) {
      if (lowerInput.includes(keyword)) {
        return restaurant;
      }
    }
  }

  return null; // No restaurant detected
}
```

### Portion Size Inference

```typescript
// If user doesn't specify portion, infer from context
function inferPortionSize(food: string, context: string): string {
  // Common defaults
  const DEFAULTS = {
    chicken: '6 oz',      // ~1.5 decks of cards
    rice: '1 cup',
    pasta: '2 oz dry',
    broccoli: '1 cup',
    egg: '1 large',
    bread: '1 slice',
    // ... more defaults
  };

  // Check if quantity mentioned
  const quantityMatch = context.match(/(\d+)\s*(oz|cup|slice|tbsp)/i);
  if (quantityMatch) {
    return `${quantityMatch[1]} ${quantityMatch[2]}`;
  }

  // Use default
  for (const [item, defaultPortion] of Object.entries(DEFAULTS)) {
    if (food.toLowerCase().includes(item)) {
      return defaultPortion;
    }
  }

  // If no default, ask user
  return null;
}
```

### Follow-Up Question Triggers

```typescript
interface ParsedFood {
  name: string;
  portion: string | null;
  preparation: string | null;
  calories: number | null;
  confidence: number; // 0-1
}

function needsFollowUp(parsed: ParsedFood): boolean {
  // Low confidence → Ask confirmation
  if (parsed.confidence < 0.6) {
    return true;
  }

  // Missing portion → Ask portion
  if (!parsed.portion) {
    return true;
  }

  // Ambiguous preparation → Ask how prepared
  if (!parsed.preparation && isProtein(parsed.name)) {
    return true;
  }

  return false;
}

function generateFollowUpQuestion(parsed: ParsedFood): FollowUpQuestion {
  if (!parsed.portion) {
    return {
      type: 'portion_size',
      question: `How much ${parsed.name}? (in ounces)`,
      options: ['3 oz', '6 oz', '8 oz', 'Other'],
    };
  }

  if (!parsed.preparation) {
    return {
      type: 'preparation',
      question: `How was the ${parsed.name} prepared?`,
      options: ['Grilled', 'Fried', 'Baked', 'Roasted', 'Other'],
    };
  }

  if (parsed.confidence < 0.6) {
    return {
      type: 'confirmation',
      question: 'Is this correct?',
      options: ['Yes', 'No, let me clarify'],
    };
  }
}
```

```typescript
function parseWeightInput(input: string): { value: number; unit: 'lbs' | 'kg' } | null {
  // Remove whitespace
  const clean = input.trim().toLowerCase();

  // Match patterns: "182.5", "182.5 lbs", "83 kg"
  const match = clean.match(/^(\d+\.?\d*)\s*(lbs?|kg)?$/);

  if (!match) {
    return null;
  }

  const value = parseFloat(match[1]);
  const unit = match[2] ? (match[2].startsWith('kg') ? 'kg' : 'lbs') : 'lbs'; // Default to lbs

  return { value, unit };
}
```
