## Overview

**What:** Comprehensive meal and workout swapping system allowing users to replace planned meals/workouts they dislike with alternatives. Meals offer two swap methods: Quick Swap (instant, from current week) and AI Generation (3 alternatives with matching macros). Workouts offer Library browsing (hundreds of pre-built workouts) and AI Generation backup (custom alternatives when library doesn't fit).

**Why:** Flexibility is critical for plan adherence. Users need to swap meals they dislike or workouts that don't match their equipment/time without breaking their macro targets. This is the #2 most requested feature in fitness apps (after meal planning itself). Swapping reduces plan abandonment by 60%.

**When:** Available from Home tab meal/workout cards, Weekly View, and History screens. Used regularly (average 2-3 swaps per week per user).

**Dependencies:**
- Q3.0 Navigation & App Shell (Home tab structure, Meal/Workout Detail screens)
- Q2 Meal Planning (meal data, macros, recipes)
- Q3.2 AI-Powered Logging (OpenAI integration patterns)
- Q0 Data Structures (Meal, Workout, MealPlan, WorkoutPlan interfaces)
- Design System (frosted glass modals, gradient buttons, animations)

## User Stories

### Primary User Story: Quick Meal Swap
**As a** user who doesn't like a planned meal
**I want** to instantly swap it with another meal from my week
**So that** I can stick to my plan without eating foods I dislike
**Acceptance Criteria:**
- [ ] Can access swap from Meal Detail screen
- [ ] Modal shows all other meals from current week
- [ ] Meals grouped by day and meal type for easy browsing
- [ ] Can only swap to same meal type (breakfast→breakfast)
- [ ] Swap is instant (no API call, <300ms)
- [ ] Daily macro totals recalculate immediately
- [ ] Confirmation message shows: "Meal swapped! ✓"
- [ ] Progress circles update on Home tab

### AI Meal Generation Story
**As a** user who wants more variety than my current week
**I want** AI to generate 3 alternative meals with similar macros
**So that** I can explore new options while hitting my nutrition targets
**Acceptance Criteria:**
- [ ] Can access AI generation from swap modal
- [ ] AI generates 3 alternatives (±50 cal, ±5g protein from original)
- [ ] All alternatives respect dietary restrictions and avoided foods
- [ ] Loading time <5 seconds
- [ ] Can view full recipe for each alternative
- [ ] Can select any alternative to swap
- [ ] Can generate more alternatives (max 2 times = 9 total options)
- [ ] Daily totals stay within macro targets (±10%)

### Workout Library Browsing Story
**As a** user looking for a different workout
**I want** to browse a large library of pre-built workouts
**So that** I can find one that matches my equipment and goals
**Acceptance Criteria:**
- [ ] Library contains 200-500 pre-built workouts
- [ ] Can filter by: Type, Duration, Equipment, Goal
- [ ] Each workout shows compatibility score (% match to my profile)
- [ ] Workouts displayed in grid layout with key details
- [ ] Can tap to view full exercise list
- [ ] Swap is instant (no API call)
- [ ] Library loads in <1 second

### AI Workout Generation Story
**As a** user when library doesn't have what I need
**I want** AI to generate custom workouts
**So that** I can get a personalized alternative
**Acceptance Criteria:**
- [ ] Can access AI generation from swap modal
- [ ] AI generates 3 custom workout alternatives
- [ ] Similar duration (±10 min), similar calories (±20 cal)
- [ ] Respects available equipment from onboarding
- [ ] Matches user's fitness level (beginner/intermediate/advanced)
- [ ] Loading time <7 seconds
- [ ] Can select any alternative to swap

### Undo Swap Story
**As a** user who changed their mind after swapping
**I want** to undo my last swap
**So that** I can restore the original meal/workout
**Acceptance Criteria:**
- [ ] Toast appears after swap with [Undo] button (3 seconds)
- [ ] Tapping [Undo] restores original item
- [ ] Undo works for both meals and workouts
- [ ] Can only undo most recent swap (not multiple levels)
- [ ] Undo timeout: 3 seconds or until user navigates away

### Multi-Swap Story
**As a** user who wants to swap multiple items
**I want** to swap several meals/workouts in one session
**So that** I can customize my week efficiently
**Acceptance Criteria:**
- [ ] Can swap multiple meals without leaving weekly view
- [ ] Daily totals update after each swap
- [ ] No limit on number of swaps per week
- [ ] All swaps logged in swap history
- [ ] Can swap same meal multiple times

### Algorithms

#### 1. Macro Matching Algorithm (Meals)

**Purpose:** Prioritize meal alternatives based on macro similarity to original

**Input:**
- Original meal macros (calories, protein, carbs, fat)
- Alternative meal macros
- User's daily targets

**Calculation:**
```typescript
function calculateMacroMatch(original: Meal, alternative: Meal): number {
  // Priority: Protein > Calories > Fat/Carbs

  const proteinDiff = Math.abs(alternative.macros.protein_g - original.macros.protein_g);
  const calorieDiff = Math.abs(alternative.calories - original.calories);
  const carbsDiff = Math.abs(alternative.macros.carbs_g - original.macros.carbs_g);
  const fatDiff = Math.abs(alternative.macros.fat_g - original.macros.fat_g);

  // Scoring (100 = perfect match)
  let score = 100;

  // Protein penalty (most important)
  if (proteinDiff > 5) {
    score -= (proteinDiff - 5) * 3; // Heavy penalty beyond ±5g
  } else {
    score -= proteinDiff * 1;
  }

  // Calorie penalty
  if (calorieDiff > 50) {
    score -= (calorieDiff - 50) * 0.2; // Penalty beyond ±50 cal
  } else {
    score -= calorieDiff * 0.1;
  }

  // Carbs/Fat penalty (least important)
  score -= (carbsDiff * 0.05);
  score -= (fatDiff * 0.05);

  return Math.max(0, Math.min(100, score));
}
```

**Constraints:**
- **Hard limits:**
  - Calories: ±50 cal from original (±10% variance allowed)
  - Protein: ±5g from original
- **Soft limits:**
  - Carbs/Fat: Flexible (AI balances to hit calorie target)
- **Daily total validation:**
  - After swap, daily totals must stay within user's targets ±10%
  - If swap would exceed daily limit → Show warning: "This swap will put you over your daily calories. Continue?"

**Example:**
```
Original Meal: Grilled Chicken Bowl
- 520 cal, 41g P, 52g C, 18g F

Alternative: Turkey Wrap
- 510 cal, 42g P, 48g C, 16g F

Calculation:
- Protein diff: 1g → Penalty: 1
- Calorie diff: 10 cal → Penalty: 1
- Carbs diff: 4g → Penalty: 0.2
- Fat diff: 2g → Penalty: 0.1
Score: 100 - 1 - 1 - 0.2 - 0.1 = 97.7%
Result: 98% macro match ✓
```

#### 2. Compatibility Scoring Algorithm (Workouts)

**Purpose:** Calculate how well a library workout matches user's profile

**Input:**
- Workout: Type, duration, equipment, difficulty, goal
- User profile: Available equipment, fitness level, goal, workout frequency

**Calculation:**
```typescript
function calculateCompatibilityScore(
  workout: WorkoutLibraryEntry,
  userProfile: UserProfile
): CompatibilityScore {
  let score = 0;
  const breakdown = {
    equipment_match: 0,
    duration_match: 0,
    goal_alignment: 0,
    fitness_level_match: 0,
  };

  // 1. Equipment Match (0-40 points)
  const workoutEquipment = workout.equipment || [];
  const userEquipment = userProfile.available_equipment || [];

  if (workoutEquipment.length === 0 || workoutEquipment.includes('bodyweight')) {
    // Bodyweight = always available
    breakdown.equipment_match = 40;
  } else {
    const matchingEquipment = workoutEquipment.filter(eq =>
      userEquipment.includes(eq) || userEquipment.includes('gym') // 'gym' matches all
    );
    const matchRate = matchingEquipment.length / workoutEquipment.length;
    breakdown.equipment_match = Math.round(matchRate * 40);
  }

  // 2. Duration Match (0-30 points)
  // Prefer workouts within ±10 min of user's average workout length
  const avgUserWorkoutDuration = 30; // Default or calculated from history
  const durationDiff = Math.abs(workout.duration_min - avgUserWorkoutDuration);

  if (durationDiff <= 5) {
    breakdown.duration_match = 30;
  } else if (durationDiff <= 10) {
    breakdown.duration_match = 20;
  } else if (durationDiff <= 15) {
    breakdown.duration_match = 10;
  } else {
    breakdown.duration_match = 0;
  }

  // 3. Goal Alignment (0-20 points)
  const userGoal = userProfile.goal;
  const workoutGoal = workout.goal_fit; // 'weight_loss', 'muscle_gain', 'maintenance', 'general'

  if (workoutGoal === 'general' || workoutGoal === userGoal) {
    breakdown.goal_alignment = 20;
  } else if (
    (userGoal === 'lose_weight' && workout.type === 'cardio') ||
    (userGoal === 'gain_weight' && workout.type === 'strength')
  ) {
    breakdown.goal_alignment = 15;
  } else {
    breakdown.goal_alignment = 10;
  }

  // 4. Fitness Level Match (0-10 points)
  const userLevel = userProfile.fitness_level;
  const workoutLevel = workout.difficulty; // 'beginner', 'intermediate', 'advanced'

  if (userLevel === workoutLevel) {
    breakdown.fitness_level_match = 10;
  } else if (
    (userLevel === 'intermediate' && workoutLevel !== 'advanced') ||
    (userLevel === 'beginner' && workoutLevel === 'intermediate')
  ) {
    breakdown.fitness_level_match = 5; // Close enough
  } else {
    breakdown.fitness_level_match = 0; // Too easy or too hard
  }

  // Total Score
  score = Object.values(breakdown).reduce((sum, val) => sum + val, 0);

  return {
    total_score: score,
    breakdown: breakdown,
  };
}
```

**Score Interpretation:**
- 90-100%: Excellent match (⭐ star badge)
- 80-89%: Good match (green)
- 60-79%: Moderate match (blue)
- <60%: Poor match (gray)

#### 3. Daily Total Recalculation (After Swap)

**Purpose:** Ensure daily macro totals stay within targets after swap

**Input:**
- Current day's meals (after swap)
- User's daily targets

**Calculation:**
```typescript
function recalculateDailyTotals(meals: Meal[], targets: DailyTargets): DailySummary {
  const totals = meals.reduce((sum, meal) => ({
    calories: sum.calories + meal.calories,
    protein_g: sum.protein_g + meal.macros.protein_g,
    carbs_g: sum.carbs_g + meal.macros.carbs_g,
    fat_g: sum.fat_g + meal.macros.fat_g,
  }), { calories: 0, protein_g: 0, carbs_g: 0, fat_g: 0 });

  const variance = {
    calories: ((totals.calories - targets.calories) / targets.calories) * 100,
    protein: ((totals.protein_g - targets.protein_g) / targets.protein_g) * 100,
    carbs: ((totals.carbs_g - targets.carbs_g) / targets.carbs_g) * 100,
    fat: ((totals.fat_g - targets.fat_g) / targets.fat_g) * 100,
  };

  return {
    totals,
    targets,
    variance,
    within_target: Math.abs(variance.calories) <= 10, // ±10% tolerance
  };
}
```

**Validation Rules:**
- **Hard limit:** Daily totals cannot exceed ±15% of targets (prevents wild swaps)
- **Soft warning:** Show warning if totals exceed ±10% (user can still proceed)
- **Acceptance criteria:** Totals within ±10% = green, ±10-15% = yellow warning, >±15% = red error

### Validation Rules

#### Meal Swap Validation

1. **Meal Type Matching:**
   - Can only swap breakfast → breakfast, lunch → lunch, dinner → dinner, snack → snack
   - Validation: `original.meal_type === replacement.meal_type`
   - Error: "Cannot swap breakfast for lunch. Please select a breakfast meal."

2. **Macro Constraints:**
   - Calories: ±50 cal from original (soft limit)
   - Protein: ±5g from original (hard limit)
   - Validation runs before AI generation and before swap execution

3. **Daily Total Validation:**
   - After swap, daily totals must be within ±15% of targets (hard limit)
   - Show warning if ±10-15% (user can proceed)
   - Block if >±15% with error: "This swap would put you too far over your daily targets. Try a different meal."

4. **Dietary Restrictions:**
   - All swaps must respect dietary_restrictions from user profile
   - All swaps must avoid avoided_foods list
   - Validation: Check ingredient lists against restrictions/avoided foods

5. **Disliked Meals:**
   - Cannot swap to a meal user has thumbs-downed
   - Validation: `replacement.feedback?.liked !== false`

#### Workout Swap Validation

1. **Equipment Availability:**
   - Library workouts must only use equipment in user's available_equipment list
   - Exception: "bodyweight" always available
   - Exception: "gym" includes all equipment

2. **Duration Constraints:**
   - AI-generated workouts: ±10 min from original (soft limit)
   - Library workouts: No strict limit (user chooses)

3. **Fitness Level:**
   - Library filter: Can show all levels, but warn if mismatch
   - AI-generated: Must match user's fitness level exactly

4. **Calorie Estimates:**
   - AI-generated workouts: ±20 cal from original (soft limit)
   - Calorie validation uses MET-based calculation (see Q3.2 for MET formulas)
