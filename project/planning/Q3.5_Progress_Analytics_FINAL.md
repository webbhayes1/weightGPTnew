## Overview

### Purpose

Q3.5 expands the Progress tab (defined in Q3.0) with comprehensive analytics, insights, and tracking features. This specification details the algorithms, data structures, and interactions for weight tracking, streaks, achievements, AI insights, body measurements, and data export.

### Scope

**In Scope:**
- Weight progress graph with trend analysis
- Weekly/monthly summary analytics with comparisons
- Streak calculation and historical tracking
- Achievement/badge unlock system (20+ badges)
- AI-powered weekly insights
- Body measurements tracking (waist, chest, arms, etc.)
- Nutrition and workout pattern analytics
- Data export (PDF, CSV, images)

**Out of Scope:**
- Social features (friend challenges, leaderboards) - deferred to V1/V2
- Advanced body composition analysis (body fat %, muscle mass %) - future feature
- Integration with external fitness devices (Apple Watch, Fitbit) - future feature

### User Stories

**As a user, I want to:**
1. See my weight progress on a graph with trend lines so I can track if I'm on track to my goal
2. View weekly and monthly summaries so I can understand my nutrition and exercise patterns
3. Track my streak so I feel motivated to maintain consistency
4. Unlock achievements so I feel rewarded for milestones
5. Get AI-generated insights so I understand what's working and what's not
6. Track body measurements beyond weight so I can see comprehensive progress
7. Export my data so I can share with my doctor, coach, or social media
8. See my favorite meals and most-logged workouts so I can identify patterns

### Related Specifications

- **Q3.0 Navigation & App Shell:** Progress tab layout, visual design, initial screen specifications
- **Q3.2 AI Logging:** LoggedMeal, LoggedWorkout, WeightEntry data structures
- **Q3.4 Weekly Planning:** Meal and workout plan generation, grocery lists
- **Design System:** Progress theme colors, graphs, animations

### With Weight Entries (≥1 Logged)

**Behavior:**
Once user logs first weight entry, it replaces starting weight as the first actual data point on graph.

**Data Points:**
- **Logged Weights:** All `WeightEntry` records for user
- Style: Filled circles, #4C9EEB (blue), 8px diameter
- Ordered chronologically on X-axis
- Y-position determined by `weight_lbs` or `weight_kg` value

**Actual Weight Line:**
- Connects all logged data points
- Style: Solid line, #4C9EEB (blue), 3px thickness
- Smooth curve interpolation (not jagged straight lines)
- Animation: Liquid fill (600ms spring) when new point added

**Trend Line (Updated):**
- Recalculated based on actual logged data + goal
- Algorithm: Linear regression from all logged weights toward goal weight
- Minimum data requirement: 2 logged weights needed for trend line
- Style: Dashed line, #E7E7E8 (light gray), 2px thickness
- Formula:
  ```
  Linear regression (least squares):
  y = mx + b
  where:
    m = Σ((xi - x̄)(yi - ȳ)) / Σ((xi - x̄)²)
    b = ȳ - m * x̄
    xi = days since start
    yi = logged weight

  Extend line to goal date
  ```

**Goal Weight Marker:**
- Remains on graph at rightmost position
- X-position: `user.goal_date`
- Y-position: `user.goal_weight`
- Style: Hollow circle, #4BAE90 (emerald), 8px diameter with emerald glow

### Progress Calculation

**% Toward Goal:**
```typescript
function calculateProgressPercent(
  startWeight: number,
  currentWeight: number,
  goalWeight: number
): number {
  const totalChange = Math.abs(goalWeight - startWeight);
  const currentChange = Math.abs(currentWeight - startWeight);

  // Ensure progress doesn't exceed 100%
  const percent = Math.min((currentChange / totalChange) * 100, 100);

  // Round to whole number
  return Math.round(percent);
}
```

**Example:**
- Start: 190 lbs
- Current: 185.2 lbs
- Goal: 175 lbs
- Total change: |175 - 190| = 15 lbs
- Current change: |185.2 - 190| = 4.8 lbs
- % toward goal: (4.8 / 15) × 100 = 32% (rounds to 32%)

**Display:**
- "X% toward goal" (18px bold, #4BAE90 emerald)
- Updates in real-time when new weight logged

### Status Indicator

**Purpose:** Shows if user is on track, ahead, or behind expected progress based on trend line comparison.

**Calculation:**
```typescript
function calculateStatus(
  currentWeight: number,
  currentDate: Date,
  startWeight: number,
  startDate: Date,
  goalWeight: number,
  goalDate: Date
): 'on_track' | 'ahead' | 'behind' {
  // Calculate expected weight at current date based on linear projection
  const daysSinceStart = daysBetween(startDate, currentDate);
  const totalDays = daysBetween(startDate, goalDate);
  const totalChange = goalWeight - startWeight;

  const expectedWeight = startWeight + (totalChange * (daysSinceStart / totalDays));

  // Determine variance (allow ±2 lbs tolerance)
  const variance = currentWeight - expectedWeight;

  if (Math.abs(variance) <= 2) {
    return 'on_track'; // Within 2 lbs of expected
  } else if (variance < -2) {
    return 'ahead'; // More progress than expected (for weight loss)
  } else {
    return 'behind'; // Less progress than expected
  }
}
```

**Status Display:**
- **On Track:** "✓ On track" (14px Semibold, #4BAE90 emerald)
- **Ahead:** "↑ Ahead of schedule" (14px Semibold, #81E296 bright green)
- **Behind:** "↓ Behind schedule" (14px Semibold, #FFB347 amber)

**Note:** For weight gain goals, logic inverts (higher weight = ahead).

### Feedback Message Adaptive Frequency (Gap 8 - Session 23)

**Purpose:** Prevent alert fatigue by adapting notification frequency based on user behavior.

**Adaptive Schedule:**

**Days 1-2 (Initial):**
- Show feedback messages **daily** if conditions met
- Example: Daily weight fluctuation notices

**Day 3 (Dismissal Option):**
- Add [Dismiss for Week] button to repeated messages
- Example:
  ```
  ⚠️ You're under your calorie goal.
     [Dismiss for Week] [View Suggestions]
  ```

**Day 7 (Forced Notification):**
- If user dismissed for week BUT condition still exists
- Show **one forced notification** on day 7
- Cannot be dismissed (must acknowledge)

**After 7 Consecutive Days:**
- Reduce frequency to **1× per week** (not daily)
- Show every Monday morning only
- Prevents fatigue while maintaining awareness

**Implementation:**
```typescript
interface FeedbackFrequencyState {
  message_type: string; // 'weight_fluctuation' | 'calorie_under' | etc
  user_id: string;
  first_shown: Date;
  days_shown_consecutively: number;
  dismissed_until: Date | null;
  last_shown: Date;
}

function shouldShowFeedback(type: string, user: User): boolean {
  const state = getFeedbackState(type, user.id);
  const now = new Date();

  // Check dismissal
  if (state.dismissed_until && state.dismissed_until > now) {
    return false; // User dismissed, respect until expiry
  }

  // Days 1-2: Show daily
  if (state.days_shown_consecutively <= 2) {
    return true;
  }

  // Day 7: Forced notification
  if (state.days_shown_consecutively === 7) {
    return true; // Force show, cannot dismiss
  }

  // After 7 days: Weekly only
  if (state.days_shown_consecutively > 7) {
    const daysSinceLastShown = daysBetween(state.last_shown, now);
    return daysSinceLastShown >= 7; // Show every 7 days
  }

  return false;
}
```

**User Controls:**
- [Dismiss for Week]: Suppresses for 7 days
- [Dismiss]: Single dismissal (shows next occurrence)
- Day 7: No dismiss button (must acknowledge)

**Analytics:**
- Track dismissal rates by message type
- Monitor if users find messages helpful vs annoying
- Adjust thresholds based on engagement data

### Week-over-Week Comparison

**Purpose:** Shows progress direction (improving vs regressing) compared to previous week.

**Data Aggregation:**
```typescript
interface WeeklySummary {
  week_start: Date; // Monday
  week_end: Date;   // Sunday
  meals_logged: number;
  workouts_logged: number;
  total_calories: number;
  total_protein_g: number;
  total_carbs_g: number;
  total_fat_g: number;
  total_exercise_minutes: number;
  total_calories_burned: number;
  days_completed: number; // Days that met criteria
}

function calculateWeeklyComparison(
  thisWeek: WeeklySummary,
  lastWeek: WeeklySummary
): string[] {
  const changes: string[] = [];

  // Meals comparison
  const mealDiff = thisWeek.meals_logged - lastWeek.meals_logged;
  if (mealDiff > 0) {
    changes.push(`↑ ${mealDiff} more meals logged`);
  } else if (mealDiff < 0) {
    changes.push(`↓ ${Math.abs(mealDiff)} fewer meals logged`);
  }

  // Exercise comparison
  const exerciseDiff = thisWeek.total_exercise_minutes - lastWeek.total_exercise_minutes;
  if (exerciseDiff > 0) {
    changes.push(`↑ ${Math.round(exerciseDiff)} more minutes exercised`);
  } else if (exerciseDiff < 0) {
    changes.push(`↓ ${Math.abs(Math.round(exerciseDiff))} fewer minutes exercised`);
  }

  // If no changes
  if (changes.length === 0) {
    return ['Same as last week'];
  }

  return changes;
}
```

**Display:**
- "vs. Last Week: " (12px gray prefix)
- Comparison text (14px Semibold)
  - **Positive changes:** #4BAE90 (emerald green) with ↑ arrow
  - **Negative changes:** #FFB347 (amber) with ↓ arrow
  - **No change:** #6E6E73 (gray)
- Multiple changes separated by comma: "↑ 2 more meals logged, ↓ 10 fewer minutes exercised"

**Edge Cases:**
- First week of using app: "No comparison yet (first week)"
- Previous week incomplete: Show comparison anyway (encourages consistency)

```typescript
function calculateWeeklyMacros(weekStart: Date, weekEnd: Date): {
  protein: { current: number; target: number };
  carbs: { current: number; target: number };
  fat: { current: number; target: number };
} {
  // Sum all logged meals for week
  const loggedMeals = getLoggedMeals(weekStart, weekEnd);

  const current = {
    protein: sumBy(loggedMeals, 'macros.protein_g'),
    carbs: sumBy(loggedMeals, 'macros.carbs_g'),
    fat: sumBy(loggedMeals, 'macros.fat_g'),
  };

  // Target = user's daily targets × 7 days
  const dailyTargets = user.daily_macro_targets;
  const target = {
    protein: dailyTargets.protein_g * 7,
    carbs: dailyTargets.carbs_g * 7,
    fat: dailyTargets.fat_g * 7,
  };

  return { protein: { current: current.protein, target: target.protein }, ... };
}
```

### Day Completion Criteria

**Purpose:** Defines what counts as a "completed day" for streak calculation.

**Completion Logic:**
```typescript
function isDayCompletedForStreak(date: Date, user: User): boolean {
  // Criteria 1: Calorie variance within acceptable range (80-120%)
  const dailyCalories = sumLoggedCalories(date);
  const target = user.daily_calorie_target;
  const caloriesMet = dailyCalories >= (target * 0.8) && dailyCalories <= (target * 1.2);

  // Criteria 2: All planned meals logged
  const plannedMeals = getPlannedMeals(date);
  const loggedMeals = getLoggedMeals(date);
  const allMealsLogged = plannedMeals.length > 0 &&
    plannedMeals.every(pm => loggedMeals.some(lm =>
      lm.logged_at.toDateString() === date.toDateString()
    ));

  // Either criteria met = day completed
  return caloriesMet || allMealsLogged;
}
```

**Notes:**
- **Calories range:** 80-120% allows flexibility (not too strict)
- **Meal logging:** Requires at least 1 planned meal exists for the day
- **OR logic:** User can meet criteria via either method (not both required)
- **Future feature:** Manual "mark day complete" override (not in MVP)

### Streak Calculation

**Daily Evaluation:**
Streak is evaluated once per day at **midnight (00:00) in user's local timezone**.

**Algorithm:**
```typescript
function calculateStreak(user: User): number {
  const today = new Date();
  const timezone = user.timezone || Intl.DateTimeFormat().resolvedOptions().timeZone;

  let streak = 0;
  let currentDate = subDays(today, 1); // Start with yesterday

  // Work backwards from yesterday, counting consecutive completed days
  while (isDayCompletedForStreak(currentDate, user)) {
    streak++;
    currentDate = subDays(currentDate, 1);

    // Safety limit: Stop at 365 days (1 year max)
    if (streak >= 365) break;
  }

  return streak;
}
```

**Streak Increment (Gap 7 - Session 23 Enhanced):**
- Runs at midnight (00:00) in user's timezone
- Background job: `DailyStreakEvaluationJob` scheduled via cron
- If previous day met criteria → Increment streak
- If previous day did NOT meet criteria → Check grace period (Gap 7):
  - **Grace Day System:** User gets 1 grace day per week (resets Monday)
  - If grace days available (`grace_days_used_this_week < 1`) → Use grace, maintain streak
  - If no grace days left → Reset streak to 0
  - **UI Notification:** "Grace day used (1/1 this week)" toast when grace applied
  - **Database:** Track `grace_days_used_this_week` field, reset every Monday 00:00
- Today doesn't count toward streak (only completed past days)

**Example:**
- User logs meals on Mon, Tue, Wed, Thu (all meet criteria)
- On Friday at 12:01 AM, streak calculation runs
- Thursday is evaluated → completed → streak = 4

**Grace Day Example (Gap 7):**
- User has 7-day streak
- Tuesday: Misses logging (doesn't meet criteria)
- Wednesday 12:01 AM: Streak evaluation runs
- System checks: `grace_days_used_this_week = 0` → Apply grace
- Streak maintained at 7 days
- Toast shows: "Grace day used (1/1 this week)"
- Database: Set `grace_days_used_this_week = 1`
- Thursday: If miss again → No grace left → Streak resets to 0
- User logs meals on Friday (meets criteria)
- On Saturday at 12:01 AM, streak calculation runs
- Friday is evaluated → completed → streak = 5

### Timezone Handling

**Purpose:** Prevent unfair streak breaks due to travel across timezones.

**Approach:**
User's "day" is defined by their **device's local timezone at the time of midnight evaluation**.

**Edge Case: Timezone Travel**
```typescript
// Example scenario:
// User in EST (UTC-5) on Monday
// Logs meals, completes day in EST
// Travels to PST (UTC-8) on Tuesday morning
// Midnight Tuesday EST passes (user asleep on plane)
// Midnight Tuesday PST arrives 3 hours later
// Streak evaluation uses PST timezone for Tuesday

// Solution: Streak calculated based on timezone where app was last opened at midnight
function getEvaluationTimezone(user: User): string {
  // Use user's last active timezone (stored in user.last_active_timezone)
  // Falls back to user.timezone from profile (Q1 onboarding)
  return user.last_active_timezone || user.timezone || 'UTC';
}
```

**Implementation:**
- **`user.last_active_timezone`:** Updated every time app opens
- Streak evaluation uses this timezone for midnight calculation
- Prevents streak break if user crosses multiple timezones in single day
- Example: User in NYC (EST) travels to LA (PST) → streak uses PST midnight

**Edge Case: International Date Line**
- If user crosses IDL (e.g., Hawaii → Japan), day can skip or repeat
- Streak calculation handles this by evaluating completed days regardless of calendar quirks
- User cannot "double-log" same calendar date to game streak (server timestamp prevents this)

```typescript
interface Achievement {
  id: string;
  name: string;
  emoji: string;
  description: string;
  unlock_condition: UnlockCondition;
  unlocked_at?: Date;
}

interface UnlockCondition {
  type: 'streak' | 'weight' | 'logging' | 'milestone' | 'performance' | 'habit' | 'nutrition' | 'fitness' | 'variety' | 'planning' | 'engagement';
  metric: string; // e.g., 'days_active', 'weight_lost_lbs', 'meals_logged'
  value: number;  // e.g., 7, 10, 100
  comparison: '>=' | '==' | '<=';
}

function checkAchievementUnlock(user: User, achievement: Achievement): boolean {
  const condition = achievement.unlock_condition;
  let userMetric: number;

  switch (condition.metric) {
    case 'days_active':
      userMetric = daysBetween(user.created_at, new Date());
      break;
    case 'weight_lost_lbs':
      const startWeight = user.current_weight; // From Q1 onboarding
      const currentWeight = getMostRecentWeight(user);
      userMetric = Math.abs(currentWeight - startWeight);
      break;
    case 'meals_logged':
      userMetric = countLoggedMeals(user);
      break;
    case 'streak_days':
      userMetric = user.current_streak;
      break;
    case 'workouts_logged':
      userMetric = countLoggedWorkouts(user);
      break;
    // ... other metrics
  }

  // Compare user's metric to unlock threshold
  switch (condition.comparison) {
    case '>=':
      return userMetric >= condition.value;
    case '==':
      return userMetric === condition.value;
    case '<=':
      return userMetric <= condition.value;
  }
}
```

  - Workout logged → Check workout achievements

```typescript
interface MacroAdherence {
  protein_adherence_pct: number; // % of target hit
  carbs_adherence_pct: number;
  fat_adherence_pct: number;
  period: 'daily' | 'weekly' | 'monthly';
}

function calculateMacroAdherence(
  startDate: Date,
  endDate: Date,
  user: User
): MacroAdherence {
  const loggedMeals = getLoggedMeals(startDate, endDate);
  const dayCount = daysBetween(startDate, endDate);

  // Sum actual macros logged
  const actual = {
    protein: sumBy(loggedMeals, 'macros.protein_g'),
    carbs: sumBy(loggedMeals, 'macros.carbs_g'),
    fat: sumBy(loggedMeals, 'macros.fat_g'),
  };

  // Calculate expected totals
  const targets = user.daily_macro_targets;
  const expected = {
    protein: targets.protein_g * dayCount,
    carbs: targets.carbs_g * dayCount,
    fat: targets.fat_g * dayCount,
  };

  // Calculate adherence %
  return {
    protein_adherence_pct: Math.round((actual.protein / expected.protein) * 100),
    carbs_adherence_pct: Math.round((actual.carbs / expected.carbs) * 100),
    fat_adherence_pct: Math.round((actual.fat / expected.fat) * 100),
    period: getPeriodType(startDate, endDate),
  };
}
```

```typescript
interface CalorieVariance {
  average_daily_calories: number;
  target_calories: number;
  min_calories: number;
  max_calories: number;
  high_variance_days: string[]; // e.g., ['Friday', 'Saturday']

function calculateCalorieVariance(
  startDate: Date,
  endDate: Date,
  user: User
): CalorieVariance {
  const dailyCalories = getDailyCalorieTotals(startDate, endDate);
  const target = user.daily_calorie_target;

  // Find days with >15% variance
  const highVarianceDays = dailyCalories
    .filter(day => Math.abs(day.calories - target) / target > 0.15)
    .map(day => getDayOfWeekName(day.date))
    .filter((day, index, self) => self.indexOf(day) === index); // Unique

    average_daily_calories: Math.round(mean(dailyCalories.map(d => d.calories))),
    target_calories: target,
    min_calories: Math.min(...dailyCalories.map(d => d.calories)),
    max_calories: Math.max(...dailyCalories.map(d => d.calories)),
    high_variance_days: highVarianceDays,
  };
}
```

```typescript
interface TopMeal {
  meal_name: string;

}

function getTopMeals(
  startDate: Date,
  endDate: Date,
  limit: number = 3
): TopMeal[] {
  const loggedMeals = getLoggedMeals(startDate, endDate);

  // Group by meal name, count occurrences
  const mealCounts = loggedMeals.reduce((acc, meal) => {
    const name = meal.meal_name;
    acc[name] = (acc[name] || 0) + 1;
    return acc;

  return Object.entries(mealCounts)

    .sort((a, b) => b.log_count - a.log_count)
    .slice(0, limit);
}
```

### Duration & Intensity Stats

**Metrics:**
- **Avg duration:** Mean workout duration across all logged workouts
- **Total time:** Sum of all workout durations
- **Calories burned:** Sum of all estimated calories (from MET values)
- **Most active days:** Days of week with most workouts logged

**Calculation:**
```typescript
interface WorkoutStats {
  avg_duration_min: number;
  total_duration_hrs: number;
  total_calories_burned: number;
  most_active_days: string[]; // e.g., ['Monday', 'Wednesday']
}

function calculateWorkoutStats(
  startDate: Date,
  endDate: Date
): WorkoutStats {
  const workouts = getLoggedWorkouts(startDate, endDate);

  // Most active days (top 3 by workout count)
  const dayOfWeekCounts = workouts.reduce((acc, workout) => {
    const day = getDayOfWeekName(workout.logged_at);
    acc[day] = (acc[day] || 0) + 1;
    return acc;
  }, {} as Record<string, number>);

  const mostActiveDays = Object.entries(dayOfWeekCounts)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 3)
    .map(([day]) => day);

  return {
    avg_duration_min: Math.round(mean(workouts.map(w => w.duration_min))),
    total_duration_hrs: Math.round((sumBy(workouts, 'duration_min') / 60) * 10) / 10,
    total_calories_burned: Math.round(sumBy(workouts, 'estimated_calories')),
    most_active_days: mostActiveDays,
  };
}
```

## Technical Requirements

### Performance Requirements

**Page Load Times:**
- Progress tab initial load: <1.5s
- Weight graph render: <500ms
- Weekly summary calculation: <300ms
- Achievement check: <200ms (background)
- AI insight fetch: <2s (or show cached)
- Export generation (PDF): <5s

**Memory Constraints:**
- Weight graph data: Max 365 data points in memory at once
- Weekly/monthly summaries: Last 12 months cached
- Achievement state: All 25 badges loaded at once (minimal overhead)
- Measurement history: Lazy load (load on demand, not all at once)

**Network Optimization:**
- Cache weight entries locally (AsyncStorage/SQLite)
- Paginate history screens (20 items per page)
- Compress export files before download
- Use CDN for share card images

**Animation Performance:**
- Target: 60 FPS for all animations
- Use native driver for transforms/opacity
- Debounce graph interactions (zoom, pan)
- Lazy render achievement badges (render only visible in viewport)

### Offline Mode Handling

**Offline Capabilities:**
- View previously loaded progress data (weight graph, summaries, achievements)
- View cached AI insights (from last fetch)
- Cannot export data (requires server)
- Cannot generate new AI insights
- Cannot refresh streak calculation (uses server timestamp)

**Offline UX:**
```
┌─────────────────────────────────────┐
│ Progress Tab                        │
│ [Offline indicator at top]          │
│                                     │
│ INSIGHTS                            │
│ ⚠️ You're offline. Showing insights │
│    from Nov 4.                      │
│    [Retry] when online.             │
│                                     │
│ [Rest of cached data displays]     │
└─────────────────────────────────────┘
```

**Sync Strategy:**
- On reconnect: Fetch latest weight entries, achievements, streak updates
- Background sync: Update AI insights if expired
- Pull-to-refresh: Force refresh all progress data

### Data Sync Strategies

**Real-Time Data:**
- Weight entries: Sync immediately when logged (optimistic UI update)
- Achievements: Check on app launch + after significant actions
- Streak: Evaluate once daily at midnight (server-side cron)

**Cached Data (7-day cache):**
- AI insights: Generated Mon 6 AM, cached until next Monday
- Weekly summaries: Cached per week (invalidate on new meal/workout log)
- Monthly summaries: Cached per month (invalidate on new entries)

**Stale-While-Revalidate:**
- Show cached progress data immediately
- Fetch fresh data in background
- Update UI when fresh data arrives (smooth transition, no flash)

**Conflict Resolution:**
- Weight entries: Server timestamp wins (prevent duplicates)
- Achievements: Server state is source of truth
- Measurements: Last write wins (optimistic locking with `version` field)

### Cache Invalidation Rules

**Weight Graph:**
- Invalidate cache when: New weight entry logged
- Cache key: `weight_graph_{user_id}_{start_date}_{end_date}`
- TTL: 24 hours

**Weekly Summary:**
- Invalidate cache when: New meal or workout logged for current week
- Cache key: `weekly_summary_{user_id}_{week_start_date}`
- TTL: 1 week (invalidates Monday 12:01 AM)

**Monthly Summary:**
- Invalidate cache when: New meal or workout logged for current month
- Cache key: `monthly_summary_{user_id}_{month_year}`
- TTL: 1 month (invalidates 1st of month at 12:01 AM)

**AI Insights:**
- Invalidate cache when: Manual refresh OR 7 days elapsed
- Cache key: `ai_insight_{user_id}_{week_start_date}`
- TTL: 7 days (invalidates Monday 6 AM)

**Achievements:**
- Invalidate cache when: New achievement unlocked OR user action (meal log, workout log, weight log)
- Cache key: `achievements_{user_id}`
- TTL: 1 hour (frequent checks for progress updates)

### Background Jobs

**DailyStreakEvaluationJob:**
- Schedule: Every day at 12:01 AM (user's timezone)
- Purpose: Evaluate previous day completion, update streak count
- Duration: <1s per user
- Batch size: 100 users per batch

**WeeklyInsightGenerationJob:**
- Schedule: Every Monday at 6:00 AM (user's timezone)
- Purpose: Generate AI insights via OpenAI API
- Duration: ~2s per user (API call)
- Batch size: 50 users per batch (rate limiting)
- Retry logic: 3 attempts with exponential backoff

**MonthlySummaryPrecomputeJob:**
- Schedule: 1st of month at 1:00 AM
- Purpose: Precompute monthly summaries for all active users
- Duration: <500ms per user
- Batch size: 200 users per batch

**AchievementCheckJob:**
- Schedule: Every hour
- Purpose: Check milestone achievements (1 month, 6 months, 1 year active)
- Duration: <100ms per user
- Only checks users with approaching milestones (optimized query)

### Error Handling

**API Failures:**
- Weight graph fails to load → Show empty state with "Unable to load graph. [Retry]"
- AI insight fails to generate → Show generic motivational message
- Export fails → Show "Export failed. Please try again. [Retry]"
- Achievement unlock fails to save → Retry in background, show achievement modal when successful

**Network Timeouts:**
- Progress data fetch timeout: 10s → Show offline mode
- Export generation timeout: 30s → Show "Taking longer than expected. We'll notify you when ready."
- AI insight timeout: 10s → Fall back to cached insight

**Data Consistency:**
- Weight entry duplicate detected → Merge (keep most recent timestamp)
- Achievement already unlocked → Ignore duplicate unlock request
- Streak calculation mismatch → Server calculation overrides client

**User-Facing Errors:**
```
Error: Unable to load progress data
[Retry] [Go Back]

Error: Export failed
Your export couldn't be generated. Please try again or contact support if the issue persists.
[Retry] [Contact Support]

Error: Insights unavailable
We couldn't generate your weekly insight. You're still doing great!
[Try Again]
```

## Algorithms

### Linear Regression (Trend Line)

**Purpose:** Calculate weight trend line from logged data points.

**Algorithm:**
```typescript
interface TrendLine {
  slope: number;     // Rate of change (lbs per day)
  intercept: number; // Y-intercept
  r_squared: number; // Goodness of fit (0-1)
}

function calculateTrendLine(weightEntries: WeightEntry[]): TrendLine {
  // Require minimum 2 data points
  if (weightEntries.length < 2) {
    return null;
  }

  // Convert dates to days since start
  const startDate = weightEntries[0].logged_at;
  const dataPoints = weightEntries.map(entry => ({
    x: daysBetween(startDate, entry.logged_at),
    y: entry.weight_lbs,
  }));

  // Calculate means
  const n = dataPoints.length;
  const meanX = dataPoints.reduce((sum, p) => sum + p.x, 0) / n;
  const meanY = dataPoints.reduce((sum, p) => sum + p.y, 0) / n;

  // Calculate slope (m) and intercept (b) using least squares
  let numerator = 0;
  let denominator = 0;

  for (const point of dataPoints) {
    numerator += (point.x - meanX) * (point.y - meanY);
    denominator += (point.x - meanX) ** 2;
  }

  const slope = numerator / denominator;
  const intercept = meanY - (slope * meanX);

  // Calculate R² (goodness of fit)
  const ssTot = dataPoints.reduce((sum, p) => sum + (p.y - meanY) ** 2, 0);
  const ssRes = dataPoints.reduce((sum, p) => {
    const predicted = slope * p.x + intercept;
    return sum + (p.y - predicted) ** 2;
  }, 0);
  const r_squared = 1 - (ssRes / ssTot);

  return {
    slope,
    intercept,
    r_squared: Math.max(0, Math.min(1, r_squared)), // Clamp to [0, 1]
  };
}

// Project trend line to future date
function projectWeight(trendLine: TrendLine, targetDate: Date, startDate: Date): number {
  const daysAhead = daysBetween(startDate, targetDate);
  return trendLine.slope * daysAhead + trendLine.intercept;
}
```

**Example:**
- Weight entries: [(day 0, 190 lbs), (day 7, 188.5 lbs), (day 14, 187 lbs), (day 21, 186 lbs)]
- Slope: -0.19 lbs/day (losing ~0.2 lbs per day)
- Intercept: 190.0 lbs
- Project to day 60: 190.0 + (-0.19 × 60) = 178.6 lbs

### Weekly Aggregation

**Purpose:** Aggregate all meal and workout data for a given week.

**Algorithm:**
```typescript
function aggregateWeeklySummary(
  user: User,
  weekStart: Date // Monday
): WeeklySummary {
  const weekEnd = addDays(weekStart, 6); // Sunday

  // Fetch all logged meals and workouts for week
  const meals = getLoggedMeals(user.id, weekStart, weekEnd);
  const workouts = getLoggedWorkouts(user.id, weekStart, weekEnd);

  // Calculate totals
  const totalCalories = meals.reduce((sum, m) => sum + m.macros.calories, 0);
  const totalProtein = meals.reduce((sum, m) => sum + m.macros.protein_g, 0);
  const totalCarbs = meals.reduce((sum, m) => sum + m.macros.carbs_g, 0);
  const totalFat = meals.reduce((sum, m) => sum + m.macros.fat_g, 0);
  const totalExerciseMin = workouts.reduce((sum, w) => sum + w.duration_min, 0);
  const totalCaloriesBurned = workouts.reduce((sum, w) => sum + w.estimated_calories, 0);

  // Calculate days completed
  let daysCompleted = 0;
  for (let i = 0; i < 7; i++) {
    const day = addDays(weekStart, i);
    if (isDayCompletedForStreak(day, user)) {
      daysCompleted++;
    }
  }

  return {
    id: generateId(),
    user_id: user.id,
    week_start: weekStart,
    week_end: weekEnd,
    meals_logged: meals.length,
    workouts_logged: workouts.length,
    total_calories: totalCalories,
    avg_calories_per_day: Math.round(totalCalories / 7),
    total_protein_g: Math.round(totalProtein),
    total_carbs_g: Math.round(totalCarbs),
    total_fat_g: Math.round(totalFat),
    total_exercise_minutes: totalExerciseMin,
    total_calories_burned: totalCaloriesBurned,
    days_completed: daysCompleted,
    created_at: new Date(),
```

### Achievement Unlock Evaluation

**Purpose:** Check if user has met conditions for achievement unlock.

**Algorithm:**
```typescript
function evaluateAchievementUnlocks(user: User): UserAchievement[] {
  const achievements = getAllAchievements();
  const userAchievements = getUserAchievements(user.id);
  const newlyUnlocked: UserAchievement[] = [];

  for (const achievement of achievements) {
    const userAch = userAchievements.find(ua => ua.achievement_id === achievement.id);

    // Skip if already unlocked
    if (userAch?.unlocked) continue;

    // Calculate current progress toward achievement
    const progress = calculateAchievementProgress(user, achievement);

    // Check if unlock condition met
    const unlocked = checkUnlockCondition(achievement.unlock_condition, progress.current);

    // Update or create user achievement record
    if (unlocked && !userAch?.unlocked) {
      const updated = {
        ...userAch,
        unlocked: true,
        unlocked_at: new Date(),
        progress_current: progress.current,
        progress_target: progress.target,
        progress_percent: 100,
        updated_at: new Date(),
      };

      saveUserAchievement(updated);
      newlyUnlocked.push(updated);

      // Show achievement unlock notification
      showAchievementNotification(achievement);
    } else if (userAch) {
      // Update progress even if not unlocked yet
      userAch.progress_current = progress.current;
      userAch.progress_percent = Math.min(100, (progress.current / progress.target) * 100);
      saveUserAchievement(userAch);
    }
  }

  return newlyUnlocked;
}

function checkUnlockCondition(condition: UnlockCondition, currentValue: number): boolean {
  switch (condition.comparison) {
    case '>=':
      return currentValue >= condition.value;
    case '==':
      return currentValue === condition.value;
    case '<=':
      return currentValue <= condition.value;
    default:
      return false;
  }
}
```
